# IT Onboarding Automation and Asset Tracking Toolkit

## Project Overview

This project provides a structured approach to IT employee onboarding, offboarding, asset management and software licence tracking for Ready IT Services.

The toolkit combines Snipe-IT for asset and licence records, Python scripts for onboarding and offboarding checklists, Ansible for provisioning demonstrations, and PowerShell for Microsoft 365 licence verification.

## Project Objectives

The main objectives are to improve consistency in IT processes, maintain accurate asset records, reduce missed onboarding and offboarding tasks, and provide written instructions that technicians can follow.

## Main Components

### Snipe-IT

Snipe-IT is used to maintain asset records, employee assignments and software licence information.

### Python

The onboarding and offboarding scripts generate checklist records in JSON format.

### Ansible

Ansible is used for a Linux-based provisioning demonstration.

### PowerShell

PowerShell is used to retrieve Microsoft 365 user and licence information when an authorised tenant is available.

## Intended Users

This toolkit is intended for IT technicians responsible for employee onboarding, device assignment, software access verification, asset recovery and offboarding administration.

## Important Limitation

Some operations may require manual approval or additional integration. The presence of a checklist does not prove that a live account, device or licence has been changed.
