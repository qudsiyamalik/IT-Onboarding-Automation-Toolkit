# Software Licence Management Runbook

## Purpose

This runbook describes how technicians maintain software licence records and review licence assignments.

## Step 1: Open the Licence Register

Open the Licences section in Snipe-IT and locate the relevant software licence record.

## Step 2: Verify Licence Details

Check the software name, licence information and recorded seat count. Ensure the record reflects the available information.

## Step 3: Review Employee Requirements

Before assigning or reclaiming a licence, confirm the employee's software requirements and follow the organisation's approval process.

## Step 4: Verify Microsoft 365 Assignment

When an authorised Microsoft 365 tenant is available, use the approved administrative interface or tested PowerShell integration to verify actual licence assignments.

## Step 5: Record Changes

Update the appropriate record after the change has been confirmed. Do not assume that a Snipe-IT record automatically updates Microsoft 365.

## Important Limitation

A licence record in Snipe-IT is an inventory record. It does not, by itself, prove that a licence has been assigned or removed in Microsoft 365.
